# TicketBooking

Ung dung Java Swing quan ly ve (tao chuyen, dat/tra ve, thanh toan, vi).

## Tong quan
Du an la ung dung desktop su dung Java Swing. Cac man hinh (frame) doc lap de mo phong quy trinh dat ve va quan ly ve.

## Tinh nang chinh
- Quan ly chuyen di (them/xoa)
- Dat ve, xem thong tin ve, huy ve
- Thanh toan va quan ly vi
- Man hinh admin va man hinh nguoi dung

## Cong nghe
- Java (Swing)
- Maven

## Yeu cau
- Java 8+ (hoac phu hop voi [pom.xml](pom.xml))
- Maven

## Chay du an
1. Build:
   - mvn clean package
2. Chay:
   - Mo bang IDE va chay lop chinh: com.mycompany.tms.TB
   - Neu muon chay bang Maven, can cau hinh exec-maven-plugin va dat mainClass = com.mycompany.tms.TB

## Cau truc thu muc
- src/main/java: ma nguon
- src/main/resources: tai nguyen (neu co)
- target: output build
